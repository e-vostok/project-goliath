## ОБЩАЯ ЧАСТЬ

### 1. Регистрация игрока

Любой пользователь может зайти в сообщество ВК и пройти процедуру регистрации (создать профиль игрока), если еще не зарегистрирован в системе игры. Регистрация через VK Launch Params (HMAC-SHA256) и `vk_user_id`. 

---

### 2. Создание и удаление государства

Игрок, зарегистрированный в проекте, может зарегистрировать новое государство. Один игрок может одновременно быть владельцем только одного государства. Один игрок = всегда одно государство единовременно.

Для регистрации государства игрок указывает уникальное название государства, уникальный HEX-код цвета государства и идентификаторы провинций, в которых будет расположено государство. После указания этой информации игрок подтверждает создание государства.

Введенные ID провинций должны существовать в базе данных.

- Все введенные ID должны быть уникальными между собой.
- Выбранные провинции должны быть свободными (не иметь привязки к другому активному государству).

Валидация географической смежности провинций отсутствует (допускается создание анклавов).

- Выбор провинций осуществляется путем ручного ввода их числовых ID в форме регистрации государства.
- Карты и провинции на данном этапе сущетсвуют лишь в базе данных и никак не визуализированы для пользователя.

Игрок может в любой момент поменять название своего государства и HEX-цвет, а также удалить свое государство. При удалении государства любые данные о государстве удаляются из базы данных.

### 3. Игровой цикл

Проект является пошаговой игрой. Игровой процесс разделён на последовательные ходы. В течение хода игрок может совершать действия. В результате этих действий накапливаются изменения в игровом мире, но не применяются мгновенно. Как только ход заканчивается, применяются все накопленные за ход изменения игрового мира и начинается следующий ход. 

Если игрок не совершил ни одного действия за ход, считается, что государство провело этот отрезок времени в пассивном режиме (бездействие). Ход завершается без изменений в показателях.

Цикл затем повторяется (счетчик ходов прибавляет единицу).

Окончание хода по прошестии определенного количества реального времени запускает процедуру обработки хода (Tick):

1. Бэкенд считывает все действия игрока в течение хода и записывает в планируемые для изменения в конце хода.
2. Во время Tick все запланированные действия применяются.
3. Рассчитываются новые показатели.
4. Изменения атомарно записываются в базу данных.
5. Игровой счетчик ходов увеличивается на 1.

Ход это глобальный период времени, действующий независимо от игроков. Момент начала и окончания хода одинаков для всех игроков. Можно регистрироваться и подключаться в любой момент на протяжении хода.

---

### 4. Течение времени в игре

Игровой мир существует в собственном времени и обладает самостоятельным календарём и системой летоисчисления. Игровой ход представляет собой определённый отрезок игрового времени, проходящий за некоторое количество реального времени. 

---

### 5. Механические деятельные акты

В течение хода игрок может совершать механические деятельные акты в виде нажатия на кнопки, расположенные на странице своего государства. При выполнении механического деятельного акта изменения игрового мира записываются как запланированные для изменения в момент Tick, то есть не применяются мгновенно.

Любой механический деятельный акт, совершенный в течение хода, считается окончательно принятым решением государства. Механика отмены или отзыва запланированных на ход действий отсутствует.

Некоторые механические деятельные акты можно выполнить только один раз за ход, некоторые несколько раз за ход, некоторые сколько угодно раз, а некоторые один раз за все время. Конкретные правила в этом отношении определяются правилами конкретного модуля.

---

### 6. Государство и сведения о нём

У каждого государства есть своя страница с указанием информации о государстве. Как только государство создается, у него есть стартовое значение его показателей по умолчанию.

Принадлежность действия ходу определяется сервером при его принятии, а не клиентским временем.

На данный момент существуют следующие показатели, отражаемые на странице государства: название государства и ID всех провинций, которые занимает это государство.
