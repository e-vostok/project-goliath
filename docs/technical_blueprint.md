### 1. Бэкенд (Движок игры, симуляция и сервисы VK)

* **Язык:** Python 3.11+ (строгая типизация через `typing` и `Pydantic v2`).
* **Фреймворк API:** FastAPI (асинхронный REST API, валидация данных, автогенерация Swagger-документации).
* **База данных и ORM:** PostgreSQL + SQLAlchemy 2.0 (asyncio) + миграции через Alembic.
* **Чтение конфигов:** `PyYAML` / `pydantic-settings` (динамическая загрузка параметров баланса из `configs/*.yaml`).
* **Авторизация и безопасность VK:**
  * Валидация подписи параметров запуска (VK Launch Params HMAC-SHA256) через секретный ключ мини-аппа (`client_secret`).
  * Полный отказ от паролей: игрок идентифицируется по проверенному `vk_user_id`.
* **Интеграция с сообществом (Бот уведомлений):**
  * Асинхронные запросы к VK API через `httpx` (или библиотеки `aiovk` / `vk-api`).
* **Тестирование:** `pytest` + `pytest-asyncio` + тестовая база данных SQLite/Postgres в памяти (соблюдение стандарта Anti-Mock Guard).

### 2. Фронтенд (Клиент VK Mini App)

* **Сборщик и ядро:** **React + TypeScript + Vite**  
  *(Примечание: для мини-аппов внутри VK на мобилках и десктопе стандарт де-факто — именно Vite SPA. Он собирается в легковесный бандл, моментально открывается в мобильном WebView без белого экрана и не требует сложного SSR-хостинга).*
* **Интерфейс и дизайн (UI):**
  * **`@vkontakte/vkui`** — официальная библиотека компонентов ВКонтакте. Приложение автоматически подстраивается под дизайн платформы (iOS, Android, десктоп) и автоматически переключает светлую/тёмную тему вслед за темой пользователя в ВК.
  * **`@vkontakte/icons`** — официальный набор векторных иконок ВК.
* **Навигация:** **`@vkontakte/vk-mini-apps-router`** (официальный роутер для бесшовного переключения между экранами/панелями).
* **Интеграция с платформой VK:**
  * **`@vkontakte/vk-bridge`** — системная шина: получение профиля (имя, аватарка), запрос разрешений на отправку сообщений от группы, тактильный отклик (haptic feedback на смартфонах при нажатии кнопок действий).
* **Карта игры:**
  * Статический векторный SVG-контур материка, встроенный внутрь компонента VKUI.
  * Заливка провинций цветами государств по их числовым ID (`fill="#HEX"`), без сложных внешних библиотек на первом этапе.

### 3. Связь клиента, сервера и платформы ВКонтакте

1. **Запросы к бэкенду:** Фронтенд отправляет запросы к FastAPI через стандартный `fetch` / Axios. В заголовке каждого запроса автоматически передается строка параметров запуска (`window.location.search`), подтверждающая личность игрока.
2. **Идентификация:** Бэкенд расшифровывает подпись ВК, находит или автоматически создает профиль с данным `vk_user_id` и возвращает состояние его государства.
3. **Хостинг фронтенда:** Статический билд Vite загружается в облако (на тот же бесплатный Vercel, VK Cloud или GitHub Pages) и вставляется ссылкой в настройках приложения в кабинете разработчика ВКонтакте (`dev.vk.com`).
