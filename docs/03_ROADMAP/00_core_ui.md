# 03_ROADMAP / 00_core_ui

> Расширение `00_core` «Единый интерфейс» (версия 0.9.0, запрошено Project Owner 19.10.2026). Правила — `docs/02_SYSTEM_SPECS/00_core_ui.md` (UI Spec); решения о составе — `docs/01_GAME_BIBLE/00_core.md` (изменения 20.10.2026) и `docs/02_SYSTEM_SPECS/00_core.md` (изменения 1.4). Единицы и их статусы ведутся в `docs/04_VERSIONS/0.9.0.md`; здесь — состав каждого Issue и определение готовности. Номера «UI-N» относятся только к этому файлу.

## Архитектурная цель расширения

Все окна приложения выглядят и ведут себя как одно приложение: верхняя полоса вместо плавающих кнопок, четыре типа окон с одинаковыми правилами, общие элементы в одном месте, одинаковые состояния и русские тексты, высота окна подстраивается под содержимое. По завершении игрок видит карточку государства, Реестр, карту, регистрацию, приказы и подтверждения в одном стиле; удалить государство игрок не может; провинции везде названиями, столица первой.

Не входит в расширение: внутренности карты и таблиц (кроме отмеченного), блок «Админ» (остаётся без изменений вида), загрузка собственных флагов и портретов, перевод интерфейса на другие языки (закладывается только структура словаря).

## Границы затрагиваемых директорий

- `frontend/src/shared/ui/` — новое: токены, шрифты, общие элементы (UI-2).
- `frontend/src/shared/` — правка: словарь текстов ошибок, ресурс высоты окна (UI-1, UI-6).
- `frontend/src/app/` — правка: `AppShell` (верхняя полоса, адреса, управление высотой окна).
- `frontend/src/modules/00_core/`, `01_map/`, `03_registry/`, `04_orders/` — правка: панели и окна переводятся на общие элементы.
- `frontend/public/assets/` — новое: логотип, шрифты (UI-2).
- `backend/src/modules/_00_core/` — правка: убирается маршрут `DELETE /api/v1/nations/me` (UI-5, сделано в 0.8.11); новый маршрут `GET /api/v1/nations/{nation_id}` и поля `level`, `judge_rating` в `NationDTO` (UI-8).
- `backend/tests/` — правка: тесты удаления государства игроком убираются, тест-ссылки бота (UI-1).
- Не затрагиваются: `deploy/`, `.env*`, `data/map/**`, движок тика, авторизация.

## Порядок выполнения

UI-0 (макеты) идёт параллельно: каждый макет готовится до кода своего окна. Код: **UI-2 → UI-1 → UI-3 → UI-6 → UI-4 → UI-5 → UI-8 → UI-7**. UI-1 берёт токены и шрифты из UI-2, поэтому UI-2 первым (в файле версии зависимость единицы 4 дополняется единицей 5).
