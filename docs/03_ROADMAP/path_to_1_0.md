## 4. Задачи Project Owner (дословные требования)

### 4.1. Версия 0.10.0

- **Лимиты полей регистрации**: полное название 50 → 60, краткое 16 → 20, описание 100 → 150, девиз 60 → 50. Лимиты лежат в `configs/00_core.yaml` и отдаются фронтенду сервером: правка баланса (трек «А»); проверить длину колонок в базе. Старых государств в игре нет (на 23.10.2026 — 0), подгонять данные не нужно.
- **Краткое название обязательно** при регистрации. Колонка `nations.short_name` сейчас необязательная; нужны: правка проверки при регистрации и правке, значение для существующих записей (записей нет), снятие «или полное» во всех местах.
- **«Штаб»**: надпись «Кратко: …» над названием государства убрать; на её месте — просто краткое название без пояснений. Длинное название показывается только в «Штабе» и в карточке государства.
- **Краткое название везде**: в Реестре (в том числе во вкладке приказов, где сейчас длинное), во всплывающих подсказках, на карте и во всех остальных местах, если прямо не указано иное.
- **Флаг вместо кружка с цветом**: рядом с названием государства везде вместо цветного кружка — маленький флаг. В Реестре государств отдельный столбец под флаг не нужен: флаг рядом с названием, как в реестре игроков в столбце «Государство».
- **Названия столбцов**: «Судейский рейтинг» → «Рейтинг»; «Дата регистрации» → «Регистрация».
- **«Приказы» в «Штабе»**: вместо блока «Неразрешённые приказы» с кружком количества — два значка: (а) приказы, поданные игроком и ожидающие вердикта; (б) приказы, полученные игроком для написания вердикта. Каждый значок открывает Реестр с уже поставленным фильтром: по авторству игрока и по судье-игроку соответственно. Кружок с числом требующих внимания приказов остаётся на значках.
- **Экран загрузки**: новый дизайн (эскиз и макет «Loading» — артефакт «PAX ATOMICA — макеты окон» версии 0.9.0) включить в приложение.
- **Профиль игрока (подокно)**: аватарка и имя ВК, дата регистрации, уровень, рейтинг, государство, за которое он играет. Уровень и рейтинг после этого убираются из «Штаба» и карточки государства. Выяснить в исследовании, откуда и как часто обновлять аватарку и имя ВК для чужих игроков.
- **Скорость загрузки** (из записки `docs/05_RESEARCH/load_speed_0.9.0.md`): дешёвые меры первыми.
- **Диагностика диска сервера (ТЕХ, единица S)**: на боевом сервере занято около 25 из 40 ГБ (23.10.2026 свободно 15 ГБ), хотя код и карта весят мало. Devin выводит самые тяжёлые папки (образы и слои Docker, журналы Docker и Caddy, резервные копии базы, журнал системы) и предлагает безопасную очистку; ничего не удаляет без команды Project Owner. Результат — записка в `docs/05_RESEARCH/` и при необходимости правка `docs/deploy_runbook.md` (автоочистка старых образов, ротация журналов). Этот результат же закрывает вопрос запаса диска для загрузки картинок игроками.

### 4.2. Версия 0.11.0 «Пульт» (админ-панель)

Выпущена 26.10.2026 (`docs/04_VERSIONS/0.11.0.md`). Исходные требования сохранены для истории.

Сначала исследование (рискованное — первым): как администратор попадает в панель в новой вкладке, где нет данных запуска ВК. Варианты: одноразовая ссылка, выданная из Mini App; вход через VK ID. Возможность открыть внешнюю страницу из Mini App в ВК не проверена.

Требования:
- Большое окно админ-панели в Mini App убирается. Вместо него — очень маленькая, едва заметная кнопка с краю, видимая только администраторам; по нажатию открывается новая вкладка браузера с панелью.
- Панель максимально простая по оформлению: минимальный базовый функциональный интерфейс. Администраторы, не знающие репозитория, пайплайна и агентов, должны сразу разобраться и быстро и точно вносить любые изменения.
- Переносятся: кнопка «Состояние», журнал ходов, «Запустить ход», удаление игрока, сброс мира.
- Новые функции: создание нового государства; удаление существующего; вывод провинции из-под контроля государства; передача провинции под контроль государства; переназначение назначенного приказа другому судье; директивное назначение неназначенного приказа судье; простой админ-лог (какие действия, когда, кем); выдача и снятие прав администратора.
- Панель растёт постепенно: новые функции модулей подключаются через реестр `AdminRegistry` (см. `docs/03_ROADMAP/admin_panel.md`).

### 4.3. Версия 0.12.0 «Изображения»

Загрузка игроками флагов и портретов правителя. Требование Project Owner (26.10.2026): версия идёт сразу после «Пульта», Балансировщик откладывается.

Исследование первым (ИССЛЕДОВАНИЕ, одно ТЗ, документ-результат в `docs/05_RESEARCH/`). Вопросы:
- Хранение: файлы на диске сервера или сами картинки в базе (после сжатия они маленькие; в базе они автоматически попадают в резервную копию, удаляются вместе со строкой и не остаются сиротами) — сравнить и рекомендовать.
- Формат и размер: проверка настоящего типа файла (не по расширению), предельный размер до и после, пережатие и приведение к фиксированному размеру и пропорциям, удаление метаданных, защита от «бомб» в картинках; как игрок обрезает картинку.
- Раздача: через Caddy как статику или через сервер приложения; кэш (адрес по содержимому).
- Квоты: по одному флагу и портрету на государство, замена удаляет прежний файл; предел загрузок в сутки на игрока.
- Резервные копии: `deploy/backup.sh` сохраняет только дамп базы — как файлы попадают в копию и в восстановление.
- Правила ВК для пользовательского контента (подтверждено, `docs/02_SYSTEM_SPECS/00_core_nat_vk_facts.md`, N1 и N5) и практический риск их невыполнения: исследование уточняет, что именно ВК проверяет у приложения с загрузкой картинок и что бывает при нарушении (по документам; непроверенное помечать).

Решение Project Owner 26.10.2026: никаких дополнительных ограничений нет — без согласия игрока при загрузке, без кнопки жалобы, без очереди «не проверено», без блокировки загрузки для игрока. Единственный инструмент контроля: администратор директивно удаляет флаг или портрет государства в разделе «Государства» панели (в окне правки государства: показ картинки, кнопка «Удалить», подтверждение, возврат к заглушке, запись в админ-лог). Это дополняет решение 0.11.0 «правка не меняет флаг и портрет»: правка по-прежнему не загружает и не подменяет картинки, только удаляет.

Принятый риск (замечание Lead AI, записано один раз): правила ВК для пользовательского контента (N1) требуют соглашения игрока, кнопки жалобы, удаления в течение 48 часов после жалобы и блокировки аккаунтов нарушителей; правка в выбранном объёме эти требования не закрывает. Последствие, которое не проверено: ВК может отклонить приложение или ограничить его при модерации либо по жалобе. Дешёвый путь вернуть соответствие правилам, если это случится: одна строка согласия в окне загрузки, кнопка жалобы и запрет загрузки игроку (небольшая версия, окна в макетах легко дополняются); поэтому окно загрузки и удаление в панели проектируются так, чтобы эти элементы можно было добавить без переделки.

Замечания Lead AI, решаются при проектировании:
- Администратор должен видеть картинки, чтобы удалять: в правке государства флаг и портрет показываются крупно; нужен и быстрый путь найти недавно загруженные (например, сортировка списка государств по дате смены картинки) — решает план версии.
- Файлы не видны тесту «забытая таблица»: сброс мира, удаление игрока и удаление государства обязаны убирать и их картинки; проверка этого — отдельная единица.
- Окна: загрузка встраивается в регистрацию и правку государства («Основные данные и символика», «Глава государства»), окно просмотра картинки и удаление в панели; макеты в двух темах утверждаются до кода (правило «макет перед кодом»); добавляется строка «что в панели?» в Промпт 6 версии.
- Решение Project Owner 27.10.2026: каталога готовых флагов и портретов нет, есть только загрузка игроком; картинка любого разрешения автоматически приводится к стандарту (флаг 600×400, портрет 600×800), при условии что флаг шире, чем выше, а портрет выше, чем шире; пока картинки нет, показывается заглушка.

### 4.4. Версия 0.13.0 «Анкеты»

Правила решены Project Owner 19.10.2026 и дополнены 23.10.2026; исходная запись — `docs/03_ROADMAP/00_core.md` («Рассмотрение анкет администратором»), штриховка резерва — `docs/03_ROADMAP/01_map.md`.

- После заполнения регистрационной анкеты она отправляется на проверку администратору по упрощённому алгоритму судейского: случайному администратору (не самому заявителю, если он сам администратор).
- Администратор получает от чат-бота ссылку, которая открывает подокно с полной заполненной анкетой. В конце он принимает решение: принять анкету или отклонить с указанием причины.
- Срок рассмотрения ровно 24 часа с момента получения (реальное время). Если анкета проигнорирована, государство принимается в игру как есть (в журнале пометка «принято автоматически»).
- С момента отправки провинции (и цвет), выбранные игроком, резервируются за ним до конца рассмотрения; на карте — полупрозрачная штриховка.
- При отклонении резерв снимается и остаётся снятым, пока игрок не отправит исправленную анкету; при повторной отправке заново идут все проверки и снова запускаются сутки.
- Игроку в любом случае приходит сообщение в чат-бот (запасной путь без согласия бота — баннер в приложении).
- Картинки анкеты администратор видит при рассмотрении и может удалить (инструмент 0.12.0, раздел 4.3); сложных автоматических проверок не делаем. Замечание: автоприём «как есть» пропускает картинки без чьего-либо просмотра — риск принят вместе с решением 26.10.2026 по картинкам.

Замечания Lead AI, которые решаются при проектировании:
- Если случайный администратор не реагирует, переназначения нет (по правилу — автоприём через сутки). Если администраторов нет, то же самое.
- Решено Project Owner 23.10.2026 (запись правил — `docs/03_ROADMAP/00_core.md`): государства в базе до принятия нет, анкета — отдельная заявка; до принятия игрок ничего в игре дополнительно не делает; число возвратов не ограничено; комментарий администратора — до 300 символов.

### 4.5. Версия 0.14.0 «Балансировщик» (отложен)

Отложен Project Owner 26.10.2026; требования сохранены без изменений.

Отдельная кнопка в панели ведёт на вкладку «Балансировщик»: один простой большой список всех единиц баланса из конфигов всех модулей, по модулям (переключатели с названиями модулей). Требования Project Owner:
- единицы появляются автоматически — читаются из актуальных `configs/*.yaml`, без ручной правки списка;
- изменение применяется в боевой игре немедленно у всех игроков, без пушей, коммитов, PR и слияний;
- таблица или простая визуализация ориентиров для долгосрочного равновесия: главные показатели каждого модуля; подсвечивать, если изменение приводит к нежелательным состояниям.

Принятые инженерные решения (Lead AI, согласовать при проектировании):
- YAML остаётся значениями по умолчанию и границами (инвариант 1). Правки администраторов хранятся в базе поверх YAML; границы проверяет та же модель, что в CI.
- Каждая правка пишется в админ-лог (кто, когда, было, стало), есть кнопка «вернуть».
- Правки применяются между ходами, не посреди расчёта (инвариант 2).
- Кнопка «выгрузить текущие значения в YAML»: чтобы Lead AI вносил их обратно в репозиторий, иначе выкладка вернёт старые числа.
- У каждой единицы нужны русское название, пояснение, единица измерения и границы; значения, зашитые во фронтенд (например, цвет границ), выносятся в конфиг.
- Ориентиры строятся только для существующих модулей и растут вместе с механиками; для несуществующих механик подсветок не выдумываем.
