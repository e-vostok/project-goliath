Решения Project Owner 27.10.2026 по макетам:

- Картинка и заглушка — кнопка загрузки. При наведении курсор становится системной рукой, через полсекунды появляется подсказка; никаких значков фотоаппарата и надписей «Заменить» поверх картинки нет.
- Метка «Загрузить» со значком фотоаппарата — только на заглушках при регистрации; в «Штабе» и в остальных окнах заглушки без надписей и значков.
- Замена картинки — щелчком по флагу или портрету в «Штабе»; картинок в окне правки текста у игрока нет.
- Суточного предела загрузок нет: при замене прежняя картинка удаляется с сервера, число загрузок не показывается.
- Тексты об ориентации: «Флаг должен быть горизонтальным: ширина больше высоты», «Портрет должен быть вертикальным: высота больше ширины».
- В панели нет раздела «Картинки»: администратор удаляет картинки в окне правки государства (раздел «Государства»).

Решения Lead AI (не возражены): портрет в «Штабе» 72 × 96 вместо 72 × 88 (пропорция 3:4); большого окна просмотра картинки нет; в окне правки государства в панели картинки показаны крупно (флаг 240 × 160, портрет 120 × 160). В боковом меню панели на этих макетах нет пункта «Картинки»; остальные экраны панели (`../0.11.0/`) не менялись.

Правило: макет — источник истины для вида окна; расхождение с макетом — дефект, если Project Owner не решил иначе.
