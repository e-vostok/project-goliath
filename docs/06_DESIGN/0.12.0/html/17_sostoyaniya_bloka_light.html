Блок картинки: состояния

Один элемент для флага и портрета. Картинка в блоке — кнопка: при наведении курсор становится рукой (системный указатель), щелчок открывает выбор файла; других значков и надписей нет. Исключение — заглушки при регистрации. В «Штабе» флаг 96×64, портрет 72×96.
