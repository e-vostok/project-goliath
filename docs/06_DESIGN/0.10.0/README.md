# Макеты версии 0.10.0 «Витрина игрока»

Источник: артефакт «PAX ATOMICA — макеты окон», доски 8–12б (утверждены Project Owner 23.10.2026).
Каждый экран — в тёмной (`_dark`) и светлой (`_light`) теме. `png/` — картинки 910 px шириной (так окно выглядит в ВК);
`html/` — те же окна статичным HTML (шрифты лежат в `fonts/`; шрифт Big Shoulders Display в картинках заменён запасным,
логотип показан серым квадратом — это ограничение выгрузки, не часть макета).
