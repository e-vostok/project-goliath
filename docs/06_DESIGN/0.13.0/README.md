# Макеты версии 0.13.0 «Анкеты»

Статус: на согласовании у Project Owner (31.10.2026). Решения версии: `docs/04_VERSIONS/0.13.0.md`; контракт анкеты: `docs/02_SYSTEM_SPECS/00_core_applications.md`.

Каждый экран — в тёмной (`_dark`) и светлой (`_light`) теме. `png/` — картинки (910 px для окон игрока, 1280 px для панели и карты); `html/` — те же экраны статичным HTML. Шрифты лежат один раз, в `../0.10.0/fonts/`; Big Shoulders Display в картинках заменён запасным, логотип показан серым квадратом, флаг, портреты и имена придуманы для макетов. Карта на доске 24 схематична (шестиугольная сетка вместо настоящих границ).
