> Статус: ПЛАН (утверждён Project Owner 19.10.2026; состав уточнён 19.10.2026 вечером; после замера окна добавлена единица 13)

## 1. Цель
Все окна приложения (вход, регистрация, карточка государства, Реестр, карта, приказы, подтверждения) выглядят и ведут себя как части одного приложения: у каждого есть тип окна со своими правилами, общая навигация, общие кнопки, состояния загрузки, ошибки, пустые состояния и сообщения об успехе. Интерфейс компактный, информативный и удобный; основа — VKUI, но приложение получает собственные оформленные графические элементы, а правила интерфейса записаны в Spec так, чтобы каждый следующий модуль строился по ним.

## 4. Риски и неизвестные
- Размер окна замерен 19.10.2026: ширина ровно 910 px, высота 3000 px (задана в кабинете dev.vk.com, допустимо до 4050), плотность пикселей 1, горизонтальной прокрутки нет. Высота — фиксированная: при короткой странице под ней пустое поле, панели `position: fixed` (Реестр, карта) растягиваются на все 3000 px, а всплывающие окна центрируются относительно этих 3000 px, а не относительно видимой части страницы ВК — возможно, игрок их не увидит. Решение Project Owner: высота должна подстраиваться под интерфейс автоматически; метод `VKWebAppResizeWindow` проверен 19.10.2026 и работает; поведение на живом каркасе проверяет единица 4.
- Окно прокручивается страницей ВК, а не самим приложением: приложению нельзя рассчитывать на «липкую» верхнюю полосу и на «видимую часть» окна без дополнительного метода ВК (`VKWebAppScroll` описан только в стороннем справочнике) — проверено 19.10.2026: внутри окна `scrollY` всегда 0, видимая часть страницы ВК приложению неизвестна, поэтому верхняя полоса не может быть «липкой», а всплывающие окна нужно размещать так, чтобы не зависеть от положения прокрутки (способ выбирает макет, единица 3; запасной вариант — прокрутка страницы к окну методом `VKWebAppScroll`, не проверен).
- Поведение закрытия всплывающих окон (Esc, клик вне окна, крестик) внутри окна ВК не проверено — смотрим в единице 1 и в приёмке единицы 6.
- Правый клик в окне выбора территорий внутри ВК: результат Project Owner не передал (запасная кнопка есть).
- Подсказка у курсора: поведение наведения с удержанием внутри iframe ВК и у краёв окна не проверено; в VKUI есть заготовки, но годность проверяет единица 11, а до этого подсказка не может быть единственным местом, где игрок видит важное.
- Постоянная верхняя полоса отнимает 50–60 px высоты у Реестра и карты — на макете (единица 3) проверить, что карта остаётся удобной.
- Ссылки из бота и меню сообщества (`#map`, `#registry`, `#registry/order-N`, `#register`) легко сломать при смене маршрутов — тест на каждую ссылку и проверка в приёмке.
- Собственные графические элементы должны корректно выглядеть в светлой и тёмной темах ВК — только через токены из единицы 5.
- Макет, сделанный Lead AI, лишь приближение к VKUI: окончательный вид проверяется на сервере в настоящем ВК; допускается один круг правок после первой выкладки.
- Удаление маршрута `DELETE /nations/me`: старые вкладки приложения могут ещё слать запрос — сервер отвечает ошибкой, клиент показывает общий текст; миграции не нужны, `NationService.delete` остаётся (его вызывает удаление тестового игрока).
- Около 40 файлов клиентских тестов привязаны к текущей разметке — смена каркаса их заденет; заложен запас квоты Devin, допустимые точки остановки: после единицы 5 и после единицы 8.
- Объём «приведения к единому виду» не ограничен сам по себе — граница задаётся списком правил Spec (единица 2) и приёмкой по снимкам.

## 5. Критерии приёмки (проверяет Project Owner в настоящем ВК)
1. Из любого окна в любое другое можно перейти через одну и ту же верхнюю полосу; плавающих кнопок нет.
2. У всех окон одного типа одинаковый вид заголовка, закрытия и «Назад»; тип окна виден по поведению (экран — в рамке, подэкран — с возвратом, всплывающее — поверх затемнения, подсказка — у курсора).
3. Все всплывающие окна закрываются одинаково, кнопки стоят в одном порядке, опасное действие выделено одинаково.
4. Загрузка, ошибка и пустая таблица выглядят одинаково и написаны по-русски; у ошибки есть «Повторить».
5. Ни у одного окна, кроме карты, нет горизонтальной полосы прокрутки; админ-блок показывает это числом.
6. Карточка государства компактная: главное видно сразу, остальное сгруппировано по блокам; кнопки «Удалить государство» нет нигде у игрока.
7. Подсказка в Реестре появляется при наведении с удержанием, исчезает при уходе курсора, не мешает кликам и не вылезает за окно.
8. Блок «Админ» остаётся на прежнем месте и работает как раньше; в нём видна строка с размером окна.
9. Ссылки из бота и из меню сообщества открывают те же окна, что раньше.
10. Работает всё прежнее: регистрация, правка государства, подача приказа и вердикт, Реестр, карта, выбор провинций.
11. Светлая и тёмная темы ВК: собственные элементы читаемы в обеих.
12. Высота окна приложения подстраивается под содержимое: под последним блоком нет пустой полосы; при переходе между окнами (карточка → Реестр → карта) высота меняется сама, без заметного мерцания; всплывающее окно открывается в видимой части экрана, а не за пределами экрана.
