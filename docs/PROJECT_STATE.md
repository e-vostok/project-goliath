## 1. Что это

Goliath (в игре и интерфейсе — «PAX ATOMICA»; прежнее игровое имя «EUROCON» отменено) — пошаговая асинхронная военно-политическая стратегия для ВКонтакте: сообщество ВК + VK Mini App + бот. Только настольные экраны (1920×1080, мышь и клавиатура), окно приложения — 910 px по ширине, кроме карты. Один ход в сутки в 00:00 по Москве, один ход равен одному игровому месяцу, игровой календарь начинается с января 2040.

## 3. Стек и устройство

- Бэкенд: FastAPI, SQLAlchemy 2.0 async, Alembic, Pydantic v2; PostgreSQL 16 на боевом сервере, SQLite в быстрых тестах; Caddy; Docker Compose. Тесты бэкенда — на SQLite и на PostgreSQL (`DATABASE_URL_TEST`).
- Фронтенд: React, TypeScript, VKUI, vk-bridge, Vitest. Сборка Docker на сервере выполняет `tsc --noEmit && vite build` вместе с тестами: ошибка типа даже в тесте останавливает выкладку.
- CI (GitHub Actions) — только ручной запуск (Actions → CI → Run workflow); запускается на `main` перед каждой выкладкой, зелёный результат обязателен. Выкладка по тегу: `cd /opt/goliath && ./deploy/deploy.sh --ref <тег>`; после успешной выкладки скрипт сам чистит кэш сборки старше 72 часов (`docs/deploy_runbook.md`, раздел 14.1).
- Конфиги баланса — `configs/<slug>.yaml`, схемы — `backend/src/modules/_<slug>/config_schema.py`. Ошибка в YAML останавливает старт и тест `pytest tests/test_configs_validity.py`.
- Пять инвариантов (подробно в `docs/development_workflow.md` и `docs/devin_rules.md`): Config-Safe, Tick DAG (5 фаз), суверенность данных, Anti-Mock Guard, безопасность сессий ВК. Исключение: `04_orders` сознательно не имеет фазы тика (фоновая задача с часами).
- Правило окон: каждое окно, кроме карты, умещается ровно в 910 px; высота окна во ВК = высота корневого контейнера приложения, её сообщает ВК единственное место — хук `useWindowHeight` (`VKWebAppResizeWindow`, пределы 600–4050).
- Интерфейс: макеты версии лежат в репозитории (`docs/06_DESIGN/<версия>/`, PNG и HTML, две темы, указатель «экран → доска»); окна строятся по этим PNG, при расхождении PNG и ТЗ побеждает PNG. Правила — UI Spec `docs/02_SYSTEM_SPECS/00_core_ui.md` (четыре типа окон: экран, подэкран, всплывающее окно S/M/L, подсказка; токены двух тем; поля; состояния). Общие элементы — `frontend/src/shared/ui`, русские тексты ошибок и успеха — `frontend/src/shared/texts/`. Каждое новое окно: макет перед кодом (Issue «Интерфейс» в Roadmap модуля), только общие элементы и токены, значения цветов «из головы» запрещены. Адреса — хеш (`#registry/nation-<id>`, `#registry/order-N`, `#map`, `#register`).
- Проверенные факты ВК про окно и интерфейс: `docs/02_SYSTEM_SPECS/00_core_ui.md` п. 2; приёмка 22.10.2026 подтвердила Esc и клик по затемнению, положение окон на высоком экране, наведение у подсказки, тему «Авто».

## 4. Модули и состояние

- **00_core** — игроки, государства, провинции, тик, календарь, авторизация ВК. С 0.10.0 краткое название государства обязательно (`nations.short_name NOT NULL`), лимиты полей 60 / 20 / 150 / 50. С 0.9.0 вместе с интерфейсом: карточка «Штаб» блоками, регистрация и правка из четырёх вкладок («Основные данные и символика», «Глава государства», «История», «Территории»), подэкран «Государство» (`GET /api/v1/nations/{nation_id}` — только публичные сведения, `NationPublicDTO`), уровень и судейский рейтинг владельца в `NationDTO`, удаление государства игроком снято (остаётся у администратора). Не закончено из v0.3.0: население и уровень развития провинций.
- **01_map** — карта мира (1067 узлов), подписи, рельеф. Выпущена в 0.6.0. Дёрганье карты в окне выбора провинций исправлено в 0.8.0.
- **02_bot** — бот сообщества: согласие, очередь, сводка хода, диалог, сообщения «государство создано». Включён на боевом сервере. Типы `ORDER_*` принадлежат `04_orders`.
- **03_registry** — окно «Реестр» (таблицы Игроки, Государства, Приказы), сортировка, фильтры, фильтр государства с выпадающим списком; с 0.10.0 показывает краткое название и маленький флаг (столбцы «Рейтинг» и «Регистрация»); щелчок по государству (оно везде обычным цветом текста) открывает подэкран, щелчок по игроку — подэкран «Игрок» (`#registry/player-<номер>`, `GET /api/v1/registry/players/{number}`); подсказки у государства и игрока; вкладка «Приказы» открывается из «Штаба» с готовым фильтром, есть фильтр «Назначены мне»; панель «Фильтры» — сетка из трёх колонок (правило в UI Spec и Spec `03_registry` 5.5). Шкалы: уровень не ниже 1; судейский рейтинг −100…+100 (константы `JUDGE_RATING_MIN/MAX` в `00_core/player_stats.py`, проверка в базе, Spec `03_registry` D1; в таблице — число со знаком, границы в подсказке и в полях фильтра); сейчас оба показателя — заглушки (1 и 0).
- **04_orders** — «Приказы»: подача, анонимный судья, вердикт, напоминание, фоновая задача, окно приказа, ссылка из бота. Закрыт в 0.7.0; в 0.10.0 в «Штабе» вместо плитки и списка «Ожидают вердикт» две карточки «Мои приказы» / «Приказы других игроков» с числом (путь судьи: карточка → Реестр → строка → окно приказа; ссылка из бота ведёт сразу в окно); приказ хранит снимок краткого названия, флага и `nation_id` государства.
- **Админ-панель** (`core/admin`) — состояние модулей в JSON, ручной ход, сброс мира (только при `ADMIN_ALLOW_RESET=true`), **удаление тестового игрока целиком** (двойное подтверждение, только для тестовых), список судей приказов.
- **deploy** — боевой сервер, бэкапы базы во внешнее хранилище (картинки в бэкап пока не входят).

## 6. Известные ограничения и долг

- Молчащий судья занимает место автора; переназначения нет (см. `docs/03_ROADMAP/04_orders.md`, бэклог).
- Уникальность названий государств пока с учётом регистра; государства до 0.8.0 без столицы и без новых полей; проверка цвета — подсказка, а не гарантия (окончательно решает сервер при создании).
- Миграция `0001` сеёт первый ход как «сейчас + 24 часа»; чистый сброс мира перед запуском для игроков — в бэклоге deploy.
- Резервные копии не покрывают файлы (картинки), только базу. Сейчас файлов игроков нет: картинки каталога лежат в репозитории.
- Скорость загрузки: в 0.10.0 сделаны дешёвые меры (предзагрузка шрифтов и логотипа, `favicon.ico`, ETag манифеста между запусками, лёгкий маршрут названий провинций, рельеф стартует раньше); остаются тяжёлая геометрия и границы карты (852 и 424 КБ) и весь JS одним куском — кандидаты 0.15.0+, `docs/05_RESEARCH/load_speed_0.9.0.md`.
- Диск сервера: причиной был кэш сборки Docker, теперь чистится автоматически; панель хостинга может показывать больше, чем `df` (гипотеза TRIM, не проверено). Подробности — `docs/05_RESEARCH/disk_0.10.0.md`.
- Бэклог 0.10.0: фильтр «Мои приказы» по краткому названию; публичный номер игрока; полоса-шкала рейтинга; артефакт макетов отстаёт от репозитория; `docs/LEAD_CONTEXT_MAP.md` устарел — полный список в `docs/04_VERSIONS/0.10.0.md`, раздел 8.
- Светлая тема: тёмная латунь значков и акцентов читается слабо — замена цвета в бэклоге `00_core_ui`.
- Номер хода: сейчас ход 0 = январь 2040, ход 1 = февраль; целевое правило «первый ход — ход 1, январь 2040» — бэклог `00_core`.
- Колонка `nations.anthem_url` и поле DTO не используются; значок исхода вердикта (успех / ограниченный успех / провал) — бэклог `04_orders`.
- Остальной долг — в разделах `## Backlog & Tech Debt` файлов `docs/03_ROADMAP/*.md`.
