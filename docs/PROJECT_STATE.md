## 1. Что это

Goliath (в игре и интерфейсе — «EUROCON») — пошаговая асинхронная военно-политическая стратегия для ВКонтакте: сообщество ВК + VK Mini App + бот. Только настольные экраны (1920×1080, мышь и клавиатура), окно приложения — 910 px по ширине, кроме карты. Один ход в сутки в 00:00 по Москве, один ход равен одному игровому месяцу, игровой календарь начинается с января 2040.

## 3. Стек и устройство

- Бэкенд: FastAPI, SQLAlchemy 2.0 async, Alembic, Pydantic v2; PostgreSQL 16 на боевом сервере, SQLite в быстрых тестах; Caddy; Docker Compose. Тесты бэкенда — на SQLite и на PostgreSQL (`DATABASE_URL_TEST`).
- Фронтенд: React, TypeScript, VKUI, vk-bridge, Vitest.
- Конфиги баланса — `configs/<slug>.yaml`, схемы — `backend/src/modules/_<slug>/config_schema.py`. Ошибка в YAML останавливает старт и тест `pytest tests/test_configs_validity.py`.
- Пять инвариантов (подробно в `docs/development_workflow.md` и `docs/devin_rules.md`): Config-Safe, Tick DAG (5 фаз), суверенность данных, Anti-Mock Guard, безопасность сессий ВК. Исключение: `04_orders` сознательно не имеет фазы тика (фоновая задача с часами).
- Правило окон: каждое окно, кроме карты, умещается ровно в 910 px.

## 4. Модули и состояние

- **00_core** — игроки, государства, провинции, тик, календарь, авторизация ВК. Часть «v0.3.0» не закончена: население и уровень развития провинций, флаг и портрет правителя. Расширение «Регистрация 2.0» запланировано в 0.8.0.
- **01_map** — карта мира (1067 узлов), подписи, рельеф. Выпущена в 0.6.0. Открыто: дёрганье карты в окне выбора провинций (бэклог).
- **02_bot** — бот сообщества: согласие, очередь, сводка хода, диалог, сообщения «государство создано». Включён на боевом сервере. Типы `ORDER_*` принадлежат `04_orders`.
- **03_registry** — окно «Реестр» (таблицы Игроки, Государства, Приказы), сортировка, фильтры, фильтр государства с выпадающим списком.
- **04_orders** — «Приказы»: подача, анонимный судья, вердикт, напоминание, фоновая задача, окно приказа, ссылка из бота. Закрыт в 0.7.0.
- **Админ-панель** (`core/admin`) — состояние модулей в JSON, ручной ход, сброс мира (только при `ADMIN_ALLOW_RESET=true`), **удаление тестового игрока целиком** (двойное подтверждение, только для тестовых), список судей приказов.
- **deploy** — боевой сервер, бэкапы базы во внешнее хранилище (картинки в бэкап пока не входят).

## 5. Действующие решения Project Owner (не пересматривать без его слова)

1. Рабочая модель: **один чат на версию**, модульные и Мастер-чат отменены (17.10.2026). Память — в файлах репозитория.
2. Обращение к Project Owner — только «вы». Простой язык без жаргона. Ответы с ручными действиями делятся на ТЗ для агента (английский) и чек-лист для Project Owner (простой русский).
3. ТЗ для агента: английский, не длиннее страницы, без таблиц, по шаблону Промпта 4, каждое ТЗ отправляется отдельным файлом; файлы документов выдаются целиком, не патчами. Git делает агент, Project Owner сливает.
4. Приказы: предел 5 неразрешённых приказов на автора (`author.max_unresolved_orders`), 5 ожидающих вердиктов на судью, порог рейтинга 0 «на время тестов», срок на вердикт 72 часа, напоминание на 75 %. Вердикт изменить нельзя. Судья анонимен для игроков; администратор видит его только в админ-панели.
5. Ссылка из бота ведёт в контекстное окно приказа (проверено Project Owner 17.10.2026 в настоящем ВК).
6. Классы слияния отчётов агента: `ROUTINE` — Project Owner сливает и выкладывает; `NEEDS LEAD AI REVIEW` — сначала Lead AI читает код через `git fetch origin pull/N/head`.
7. Названия в игре — EUROCON; «Goliath» остаётся во внутренних названиях проекта и репозитория.

## 6. Известные ограничения и долг

- Молчащий судья занимает место автора; переназначения нет (см. `docs/03_ROADMAP/04_orders.md`, бэклог).
- Нестабильный тест `test_clock_moved_during_sleep_is_honoured` (`00_core`), падает редко на одинаковом коде.
- Миграция `0001` сеёт первый ход как «сейчас + 24 часа»; чистый сброс мира перед запуском для игроков — в бэклоге deploy.
- Резервные копии не покрывают файлы (картинки), только базу.
- Остальной долг — в разделах `## Backlog & Tech Debt` файлов `docs/03_ROADMAP/*.md`.
