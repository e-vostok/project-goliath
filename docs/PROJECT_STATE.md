## 1. Что это

Goliath (в игре и интерфейсе — «PAX ATOMICA»; прежнее игровое имя «EUROCON» отменено) — пошаговая асинхронная военно-политическая стратегия для ВКонтакте: сообщество ВК + VK Mini App + бот. Только настольные экраны (1920×1080, мышь и клавиатура), окно приложения — 910 px по ширине, кроме карты. Один ход в сутки в 00:00 по Москве, один ход равен одному игровому месяцу, игровой календарь начинается с января 2040.

## 3. Стек и устройство

- Бэкенд: FastAPI, SQLAlchemy 2.0 async, Alembic, Pydantic v2; PostgreSQL 16 на боевом сервере, SQLite в быстрых тестах; Caddy; Docker Compose. Тесты бэкенда — на SQLite и на PostgreSQL (`DATABASE_URL_TEST`).
- Фронтенд: React, TypeScript, VKUI, vk-bridge, Vitest. Сборка Docker на сервере выполняет `tsc --noEmit && vite build` вместе с тестами: ошибка типа даже в тесте останавливает выкладку.
- CI (GitHub Actions) — только ручной запуск (Actions → CI → Run workflow); запускается только на релизах (решение Project Owner 24.10.2026); перед выкладкой промежуточных PATCH-версий CI не запускают и не ждут. Выкладка по тегу: `cd /opt/goliath && ./deploy/deploy.sh --ref <тег>`; после успешной выкладки скрипт сам чистит кэш сборки старше 72 часов (`docs/deploy_runbook.md`, раздел 14.1).
- Конфиги баланса — `configs/<slug>.yaml`, схемы — `backend/src/modules/_<slug>/config_schema.py`. Ошибка в YAML останавливает старт и тест `pytest tests/test_configs_validity.py`.
- Пять инвариантов (подробно в `docs/development_workflow.md` и `docs/devin_rules.md`): Config-Safe, Tick DAG (5 фаз), суверенность данных, Anti-Mock Guard, безопасность сессий ВК. Исключение: `04_orders` сознательно не имеет фазы тика (фоновая задача с часами).
- Правило окон: каждое окно, кроме карты, умещается ровно в 910 px; высота окна во ВК = высота корневого контейнера приложения, её сообщает ВК единственное место — хук `useWindowHeight` (`VKWebAppResizeWindow`, пределы 600–4050).
- Интерфейс: макеты версии лежат в репозитории (`docs/06_DESIGN/<версия>/`, PNG и HTML, две темы, указатель «экран → доска»); окна строятся по этим PNG, при расхождении PNG и ТЗ побеждает PNG. Правила — UI Spec `docs/02_SYSTEM_SPECS/00_core_ui.md` (четыре типа окон: экран, подэкран, всплывающее окно S/M/L, подсказка; токены двух тем; поля; состояния). Общие элементы — `frontend/src/shared/ui`, русские тексты ошибок и успеха — `frontend/src/shared/texts/`. Каждое новое окно: макет перед кодом (Issue «Интерфейс» в Roadmap модуля), только общие элементы и токены, значения цветов «из головы» запрещены. Адреса — хеш (`#registry/nation-<id>`, `#registry/order-N`, `#map`, `#register`).
- Проверенные факты ВК про окно и интерфейс: `docs/02_SYSTEM_SPECS/00_core_ui.md` п. 2; приёмка 22.10.2026 подтвердила Esc и клик по затемнению, положение окон на высоком экране, наведение у подсказки, тему «Авто».

С 0.11.0 даёт панели администратора: журнал администратора (`admin_audit_log`, не более `admin_panel.audit_log_max_rows` = 5000 записей), права администраторов в базе (`admin_grants`; администраторы из `.env` неснимаемы), создание, правку и удаление государства, передачу и вывод провинций. С 0.10.0 краткое название государства обязательно (`nations.short_name NOT NULL`), лимиты полей 60 / 20 / 150 / 50. С 0.9.0 вместе с интерфейсом: карточка «Штаб» блоками, регистрация и правка из четырёх вкладок («Основные данные и символика», «Глава государства», «История», «Территории»), подэкран «Государство» (`GET /api/v1/nations/{nation_id}` — только публичные сведения, `NationPublicDTO`), уровень и судейский рейтинг владельца в `NationDTO`, удаление государства игроком снято (остаётся у администратора). Не закончено из v0.3.0: население и уровень развития провинций. С 0.12.0 игрок сам загружает флаг (600×400) и портрет (600×800): любой размер приводится по центру, предпросмотр, WebP с миниатюрами, хранение в PostgreSQL (`nation_images`, bytea); каталога готовых картинок нет (миграция 0017), без картинок — заглушки; `PUT /api/v1/nations/me/images/{kind}`, раздача `GET /api/v1/images/{sha256}/{full|thumb}` с кэшем на сутки, адреса строит только `images.image_url` (INV-16), чтение для модулей — `NationService.image_refs`; суточного предела нет; администратор удаляет картинку в правке государства (запись `nation_image_delete`); сброс мира, удаление игрока и государства убирают картинки.  С 0.13.0 регистрация заканчивается анкетой (Spec `00_core_applications.md`): игрок отправляет, отменяет или правит её (после отмены и возврата — черновик), любой администратор, кроме заявителя, принимает или возвращает с причиной до 300 символов, без решения через `applications.review_hours` (24) анкета принимается сама фоновой задачей; на рассмотрении зарезервированы провинции, цвет, полное и краткое название; «Штаб» заменён окном анкеты; рецензента нет (колонки `reviewer_*` не используются).

- **02_bot** — бот сообщества: согласие, очередь, сводка хода, диалог, сообщения «государство создано». Включён на боевом сервере. Типы `ORDER_*` принадлежат `04_orders`. С 0.13.0 пять типов анкет: игроку — получена, возвращена, принята (в том числе автоматически), каждому администратору с согласием — «поступила анкета» со ссылкой `#application/<id>`; плитка «Бот» в «Ход и мир».

С 0.12.0 в ячейках «Государство» таблиц и в подсказках — миниатюра загруженного флага (у государства без флага — блок цвета).
- **04_orders** — «Приказы»: подача, анонимный судья, вердикт, напоминание, фоновая задача, окно приказа, ссылка из бота. Закрыт в 0.7.0; с 0.11.0 администратор назначает и переназначает судью из панели (без порога рейтинга и предела, без сообщений бота, таймеры идут заново); в 0.10.0 в «Штабе» вместо плитки и списка «Ожидают вердикт» две карточки «Мои приказы» / «Приказы других игроков» с числом (путь судьи: карточка → Реестр → строка → окно приказа; ссылка из бота ведёт сразу в окно); приказ хранит снимок краткого названия, флага и `nation_id` государства. С 0.12.0 флаг в приказе берётся у государства по `nation_id` из текущего состояния (у удалённого государства — заглушка); название и цвет остаются снимком.
- **Панель администратора** (`core/admin`, клиент `admin.html`) — отдельная страница в новой вкладке браузера (с 0.11.0, ширина 1280 px); вход — едва заметный щит в «Штабе» (виден только администратору), одноразовая ссылка во фрагменте адреса живёт 60 секунд и меняется на сеанс в 60 минут; права перечитываются из базы при каждом запросе. Файл `docs/03_ROADMAP/admin_panel.md`. С 0.13.0 в «Государствах» подраздел «Анкеты» (список со счётчиком, «Открыть» ведёт в окно анкеты Mini App; окна анкеты внутри панели нет), плитки «Анкеты» и «Бот», щит в «Штабе» подсвечен при вопросе, требующем внимания (`AdminRegistry.register_attention`, `GET /admin/attention`). С 0.12.0: в окне правки государства блок «Картинки государства» (крупно, дата, кто загрузил, размер, «Удалить» с подтверждением и записью в журнале), в списках «Государства», «Приказы», «Провинции» настоящие флаги; администратор только удаляет картинки, загрузить или заменить не может.

## 6. Известные ограничения и долг

- Молчащий судья занимает место автора; автоматического переназначения нет — администратор переназначает вручную в панели (0.11.0); автоматическое переназначение — в бэклоге `04_orders`.
- Уникальность названий государств пока с учётом регистра; государства до 0.8.0 без столицы и без новых полей; проверка цвета — подсказка, а не гарантия (окончательно решает сервер при создании).
- Миграция `0001` сеёт первый ход как «сейчас + 24 часа»; чистый сброс мира перед запуском для игроков — в бэклоге deploy.
- Резервные копии: картинки лежат в базе и входят в `pg_dump`; восстановление картинок проверено Project Owner 31.10.2026 по `restore_check.sh` (вывод строки `nation_images` Lead AI не видел). Рост дампа — десятки мегабайт, диск смотреть при росте числа загрузок.
- Скорость загрузки: в 0.10.0 сделаны дешёвые меры; остаются тяжёлая геометрия и границы карты (852 и 424 КБ) и весь JS одним куском — кандидаты 0.15.0+, `docs/05_RESEARCH/load_speed_0.9.0.md`.
- Диск сервера: причиной был кэш сборки Docker, теперь чистится автоматически; панель хостинга может показывать больше, чем `df` (гипотеза TRIM, не проверено). Подробности — `docs/05_RESEARCH/disk_0.10.0.md`.
- Светлая тема: тёмная латунь значков и акцентов читается слабо — замена цвета в бэклоге `00_core_ui`.
- Номер хода: сейчас ход 0 = январь 2040, ход 1 = февраль; целевое правило «первый ход — ход 1, январь 2040» — бэклог `00_core`.
- Колонка `nations.anthem_url` и поле DTO не используются; значок исхода вердикта (успех / ограниченный успех / провал) — бэклог `04_orders`.
- Бэклог 0.12.0 (`docs/04_VERSIONS/0.12.0.md`, раздел 8): правила ВК для пользовательских картинок не закрыты (принятый риск); у администратора нет ленты свежих загрузок; Реестр отдаёт `Cache-Control: no-store` без ETag; правка текстов щелчком; удалить ветку `feat/images-0-12-0-u5a-pipeline`.
- Бэклог 0.13.0 (полный список — `docs/04_VERSIONS/0.13.0.md`, раздел 8): опрос окна анкеты при ошибке заменяет окно ошибкой и останавливается; подэкран администратора и «назад» идут через push (ловушка истории); в DTO администратора нет имени решившего и времени отмены; снять колонки `reviewer_*` миграцией; замер карты (p95 +24 %) повторить на реальной карте.
- Backlog: the section «Backlog & Tech Debt» of each docs/03_ROADMAP/*.md (single source).
