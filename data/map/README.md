# data/map — файловые данные карты

| Файл | Кто пишет | Содержимое |
| --- | --- | --- |
| `source/map.svg` | зафиксирован | Исходный SVG карты MapChart (~6,6 МБ). Коммитится один раз, не редактируется. |
| `boundary.yaml` | Project Owner | Утверждённый перечень провинций игрового поля (`include`) и явные исключения (`exclude_explicit`). |
| `overrides.yaml` | Project Owner | Ручные данные: морские зоны, проливы, `drop_parts`/`keep_parts`, ручные связи, технические контуры, русские названия. Схема — в `docs/02_SYSTEM_SPECS/01_map.md`. |
| `ids.lock.json` | инструмент | Соответствие `key → id`. **Только пополняется, никогда не правится вручную** (INV-M1): идентификаторы не переиспользуются и не перенумеровываются. |
| `manifest.json` | инструмент (MP-3) | Узлы, связи, версия геометрии, геопривязка, хэши входных файлов. |
| `geometry.json` | инструмент (MP-3) | Контуры узлов и контур «земель за краем». |
